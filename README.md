# FlexAI

**Переводчик, который думает сам** — голосовой и текстовый перевод в реальном времени, работающий прямо на телефоне, без обязательной отправки данных в облако.

## О проекте

FlexAI — Android-приложение для устного и письменного перевода. Ключевая идея — перевод может выполняться **полностью локально**, на самом устройстве, с аппаратным ускорением на чипах Qualcomm. При этом доступен и режим работы через удалённый сервер, если нужна модель помощнее или локальных ресурсов не хватает.

Приложение подойдёт как разговорник для живого общения (диктуешь фразу — получаешь перевод голосом и текстом), так и как обычный переводчик с сохранением истории переписки.

## Возможности

- **Голосовой перевод в реальном времени** — говоришь в микрофон, приложение само определяет начало и конец фразы (VAD), распознаёт речь, переводит и озвучивает результат.
- **Текстовый режим** с историей переводов в виде чата — можно вернуться к любому прошлому диалогу.
- **Полный офлайн-режим**: языковая модель работает прямо на устройстве, интернет не нужен.
- **Аппаратное ускорение на Qualcomm NPU** — приложение само определяет чипсет устройства и подбирает под него оптимальную библиотеку, чтобы модель считалась быстро и без лишнего расхода батареи.
- **Гибкий выбор движков распознавания и синтеза речи** — локальные или сторонние STT/TTS-движки, установленные на устройстве.
- **Менеджер моделей** — скачивание готовых моделей «из коробки», импорт своих файлов моделей, диагностика проблем загрузки.
- **Онбординг** — при первом запуске приложение само подскажет, какие модели скачать для старта.
- **HUD с метриками** — скорость перевода, задержка и прочая техническая телеметрия для тех, кому интересно, «что там под капотом».
- **Облачный режим** — как альтернатива локальным моделям, можно подключить собственный сервер/API.
- **Тёмная и светлая тема.**

## Как это устроено

```
Микрофон → определение речи (VAD) → распознавание речи (STT)
   → перевод (локальная LLM на NPU  ИЛИ  запрос к серверу)
   → синтез речи (TTS) → ответ показывается в чате и озвучивается
```

Перевод можно получить двумя путями:

1. **Локально** — на устройстве работает компактная языковая модель
   (формат `.litertlm`, движок LiteRT-LM), а тяжёлые вычисления
   выполняет NPU/DSP чипа Qualcomm, а не обычный процессор — это
   быстрее и экономичнее по батарее.
2. **Через сервер** — приложение можно направить на внешний API,
   если нужна модель мощнее, чем может унести телефон.

Выбор между этими режимами — дело пользователя, оба настраиваются в
приложении.

## На чём построено

| Слой                         | Технология                                            |
|-------------------------------|--------------------------------------------------------|
| Язык / UI                     | Kotlin, Jetpack Compose (Material 3)                   |
| Локальный AI-движок           | LiteRT-LM (Google AI Edge)                              |
| Аппаратное ускорение           | Qualcomm QNN (Hexagon NPU/DSP)                          |
| Сеть (облачный режим)          | OkHttp                                                   |
| Асинхронность                  | Kotlin Coroutines                                        |
| Распознавание/синтез речи       | подключаемые STT/TTS-движки (системные и сторонние)      |

## Требования

- Android 8.0 (API 26) и новее.
- Для полностью локальной работы — устройство на чипе Qualcomm
  Snapdragon с поддержкой NPU. На других чипах доступен облачный режим.

## Сборка проекта
